# Comment Desk (Android app)

Day -> Post -> comments paste karein -> Urdu matlab + chhota human reply (Google Gemini se).

## APK kaise banegi (GitHub, free)
1. github.com par free account banayein, naya khali repository banayein (jaise `comment-desk`).
2. Is folder ki saari files us repository mein upload karein (`.github` folder samet).
3. Repository mein **Actions** tab kholein. "Build APK" apne aap chalegi (5-8 minute). Na chale to "Run workflow" dabayein.
4. Run khatam hone par us par click karein, neeche **Artifacts** mein `CommentDesk-apk` download karein (zip hai, usmein `app-debug.apk`).
5. Phone mein APK kholein, "Install unknown apps" ki ijazat dein, install karein.

## Pehli baar
App kholein -> Settings (gear) -> Gemini API key paste karein (aistudio.google.com/apikey se free key milti hai) -> Save karein.
Key sirf aap ke phone mein save hoti hai.
